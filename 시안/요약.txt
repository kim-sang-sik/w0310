## 마크업 기본 문법 규칙

### 요소는 시작 태그와 종료 태그가 있어야 한다.

```jsx
<시작태그>내용</종료태그>

<h1>제목</h1>
<p>나는 단락이다.</p>
```

### 단, 태그 중에는 종료 태그가 없는 요소도 있다. → 빈 요소(empty element)

```html
<br>, <hr>, <img>, <input>, <meta>, <link>
```

### 요소는 제대로 중첩되어야 한다.

```jsx
<p>나는 
	<strong>문단</strong>이다.
</p>
```

잘못된 표현

```html
<p>나는 <strong>문단</p>이다.</strong>
```

### img 태그에는 alt 속성이 있어야 한다. → 웹 접근성

HTML 태그마다 속성이 정해져 있으며, 필수 속성(반드시 사용!)과 선택 속성(글로벌 속성)으로 구분된다.

글로벌 속성에는 id, class, title, style 등이 있다.

```html
<시작태그 속성="값" 속성="값" 속성="값" ...>내용</종료태그>

<img src="./[경로/]파일명.jpg alt="대체 텍스트" width="400">
<img src="./[경로/]파일명.png alt="대체 텍스트" height="200">
<img src="./[경로/]파일명.gif alt="대체 텍스트" style="width:400px;"> -> 인라인 CSS
<img src="./[경로/]파일명.svg alt="대체 텍스트">

위에서 src와 alt는 필수 속성이다.
```

### 태그명과 속성명은 대소문자를 구별하지 않는다.

→ 그러나, 소문자로 마크업 하는 것을 권장한다.

```html
<p>나는 단락이다.</p>         (권장)
<P>나는 단락이다.</P>
```

### 속성 값은 큰 따옴표(” ”)로 묶는 것을 권장한다.

```html
<img src="./경로/이미지.png" alt="대체 텍스트">    (권장)
<img src=./경로/이미지.png alt=대체 텍스트>
```

블록 레벨 요소(Block-level Elements) VS 인라인 요소(Inline Elements)

| 구분 |  |
| --- | --- |
| 블록 레벨 요소 | 줄 바꿈이 있다.
텍스트(문자)와 인라인 요소를 자식 요소로 포함할 수 있다.
블록 레벨 요소를 자식으로 포함 할 수 있는 요소와 포함할 수 없는 요소가 있다.
<div>, <header>, <footer>, <section>, <main>, <article>, <aside>, <nav>,
<hn>, <p>, <pre>, <ul>, <li>, <ol>, <dl>, <dt>, <dd>, <form>, <fieldset>, <figcation>, <figure>, <table>, <thead>, <tbody>, <tfoot>, <blockquote>, … |
| 인라인 요소 | 줄 바꿈이 없다.
인라인 요소의 자식으로 블록 레벨 요소를 사용할 수 없다.
인라인 요소는 텍스트(문자)와 인라인 요소를 자식 요소로 포함할 수 있다.
<span>, <a>, <img>, <map>, <video>, <audio>, <br>, <q>
<input>, <textarea>, <label>
<strong>, <b>, <em>, <i>, <mark>, <small>, <sup>, <sub>, <del>, <ins>, 
<kbd>, <code>, <samp>, <var>, … |

### 인라인 요소의 자식으로 블록 레벨 요소를 사용할 수 없다.

```html
<b>나는 <p>단락</p>이다.</b>     (x)
<span><h1>제목</h1></span>      (x)

<h1><span>제목</span></h1>      (o)
<p>나는 <b>단락</b>이다.</p>     (o)
```

텍스트(문자)와 인라인 요소를 자식 요소로 포함할 수 있다.

# CSS 지정 방법

### 내부 스타일(Internal CSS)

HTML의 style 태그 사이에 기록한다.

```jsx
<style>
		/* HTML의 style 태그 사이에 기록하는 방식 */
</style>
```

### 외부 스타일(External CSS)

link 태그를 이용하여 *.css 파일을 연결한다.

```jsx
<link rel="stylesheet" href="경로/*.css">
```

### 인라인 스타일(Inline CSS)

HTML 태그의 style 속성을 이용하여 지정한다.

```jsx
<태그 style="속성명: 값;">
```

## CSS의 형식

```css
선택자 {선언부}
선택자 {선언; 선언; 선언; ...}
선택자 {속성: 값; 속성: 값; 속성: 값; ...}
```

또는

```css
선택자 {
		속성: 값;
		속성: 값;
		속성: 값;
		...
}
```

## CSS 선택자(선택기, selector)

| 선택자 | 종류 |
| --- | --- |
| 기본, 간단
Simple | **type, id, class, 전체, 그룹** |
| 결합자
Combinator | 하위, 자식, 인접 형제, 형제, 종속 |
| 가상 클래스
Pseudo-class | :link, :visited, **:hover**, :active, :focus |
| 가상 요소
Pseudo-element | :first-letter, :first-line, :first-child, :last-child, :nth-child(n), :first-of-type, :last-of-type,  :nth-of-type(n), **:before, :after** |
| 속성
Attribute | [속성], [속성=”값”], [속성~=”값”], [속성|=”값”], [속성^=”값”], [속성$=”값”], [속성*=”값”] |

### 아이디와 클래스 이름 규칙

1. 첫 글자는 영문자와 특수문자는 _(언더바)와 -(하이픈)
2. 두 번째 문자부터는 영문자와 특수문자(_, -), 숫자의 조합
3. 영문자는 대소문자를 구별한다.
